# 日语小说下载器

适用于下载日语小说的桌面工具，可导出为纯文本或 ePub3 文件。

## 主要功能

- 从受支持的小说链接下载日语小说
- 导出为纯文本和 ePub3
- 支持断点续传和检查新章节
- 可由本地文本生成 ePub3，或将 ePub3 转换回文本
- 提供简易 Windows 图形界面

## 运行环境

- Python 3.10 或更高版本
- 部分下载来源和功能需要安装额外依赖

## 快速开始

```bash
python novel_downloader.py "<日语小说链接>"
```

使用 `python novel_downloader.py --help` 查看可用选项。
